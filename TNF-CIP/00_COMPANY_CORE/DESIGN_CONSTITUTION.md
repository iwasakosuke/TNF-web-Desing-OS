# DESIGN_CONSTITUTION

TNF-CIP全社員（10 Divisions / 全AI社員）が従う最上位のデザイン規範。
QUALITY_STANDARD.mdが「何を検査するか」を定めるのに対し、本ファイルは
「なぜその基準なのか」という思想と判断原則を定める。両者は対であり、
本ファイルなしにQUALITY_STANDARD.mdのチェックリストを機械的に運用すると
形骸化するため、必ずセットで参照する。

## ミッション

「テンプレートで作られたように見えない」を、感覚ではなく検証可能な原則として定義し、
どのDivision・どのAI社員が制作してもApple／Linear／Stripe／Framer／Aesop／
Blue Bottle Coffee水準の洗練度を再現できる状態を作ること。TNF-CIPの全成果物は、
最終的にこの憲法への準拠度で合否が決まる。

## 実務での役割

- 新規プロジェクト開始時、Master_Creative_Director_AIとStrategy_Divisionが
  最初に読み込み、案件固有の制約と本憲法の優先順位を確認する
- Design_Division・Visual_Division・Motion_Divisionは、それぞれの専門判断が
  本憲法と矛盾しないかを常に自己チェックする
- QA_DivisionのDesign_Reviewer_AIは、QUALITY_STANDARD.mdのチェック結果が
  「なぜその基準なのか」を説明できない場合、本ファイルに立ち返って再判定する
- 03_STYLE_DNA・04_VISUAL_DNAは本憲法の「解釈」であり「例外」ではない。
  矛盾が生じた場合は本憲法が優先される

## 判断基準

洗練されたデザインと素人っぽいデザインを分ける要因は「装飾の量」ではなく
「意思決定の精度」である。本憲法では、以下5つの軸で意思決定の精度を測る。

1. **抑制（Restraint）**: 使える選択肢のうち、実際に使うのは何割か。色数・フォント数・
   モーションパターン数が少ないほど、各要素の意味が強くなる
2. **整合（Coherence）**: 余白・角丸・影・トランジション速度など、一度決めた「単位」が
   ページ全体、サイト全体、さらには他案件をまたいでも一貫しているか
3. **階層（Hierarchy）**: 視線がどこから始まりどこで終わるか、意図通りに誘導できているか。
   すべてが強調されている状態は、何も強調されていない状態と同義である
4. **間（Whitespace as Content）**: 余白は「余り」ではなく「情報」である。呼吸がない
   レイアウトは、内容の価値に関わらず安っぽく見える
5. **手触り（Craft）**: ホバー時の反応速度、影の落ち方、文字のカーニングなど、
   1px・1msのレベルで詰められているか。ここの雑さが「テンプレート感」の正体である

## 入力フォーマット

```
- 案件名 / 業種 / 担当Division
- ターゲットユーザー像
- 参照ブランドDNA（03_STYLE_DNAから1〜2件、または04_VISUAL_DNAの業種）
- トーン指定（あれば）: フォーマル / カジュアル / ラグジュアリー 等
- 既存ブランド資産の有無（ロゴ・カラー・フォントの制約）
```

## 出力フォーマット

本憲法自体は出力物を持たない。ただし、本憲法を適用した結果としてすべての制作物は
以下を明示できる状態でなければならない。

```
- 使用色数（何色に絞ったか、なぜその色か）
- 使用フォント（見出し/本文/補助の役割別に何を使ったか）
- 余白の基準単位（例: 8px grid, 4px grid）
- モーションの基準速度・イージング
- この案件で「あえてやらなかったこと」のリスト
```

## 品質基準

- **配色**: 主要カラーは3〜5色以内。うち有彩色のアクセントは1〜2色まで
- **フォント**: 見出し用・本文用をあわせて2〜3書体以内。ウェイトは3段階以内
- **余白**: 単一の基準単位（4px or 8px）の倍数のみを使用。中途半端な13px, 22pxは禁止
- **角丸**: サイト内で使う角丸の値は多くて2〜3種類。用途別に明確に分離されている
- **影**: 使用は最小限。使う場合は1〜2段階のみで、装飾目的の多重影は禁止
- **モーション**: 200〜400ms、easeOut系を基本とする
- **コピー**: 一文が長すぎない。誇張的な最上級表現の乱用禁止
- **画像**: すべての画像に「なぜこの構図・光・トーンなのか」の説明が付けられる状態であること

## NG例

- グラデーションを「とりあえず映えるから」という理由だけで使用すること
- ストックフォトそのままの、文脈のない笑顔ビジネスパーソン素材の使用
- Bootstrap/無料テーマ由来の見慣れたカードシャドウの丸写し
- 「とりあえず全部アニメーションさせる」という判断の放棄
- 参照ブランド（Apple等）のビジュアルをそのまま模倣し、固有名詞やロゴだけ差し替える行為
- セクション数・要素数を情報量ではなく「見栄え」のために水増しすること

例:
```
1ページ内に5色以上の有彩色が登場し、どれが最重要のアクションカラーか判別できない。
角丸も4種類以上バラバラで、ボタンごとに微妙に異なる値が使われている。
```

## 良い例

- Stripeのヒーローセクション: 背景はグラデーションメッシュ1種類のみに抑制しつつ、
  情報階層はコピー→ビジュアル→CTAの一直線。装飾と機能が完全に分離されている
- Linearのダッシュボード風LP: 色数を極限まで絞り、バイオレット1色のみをアクセントとして
  「ここぞ」という場所（CTA、アクティブ状態）にのみ使用している
- Aesopの製品ページ: セリフ体1書体+サンセリフ1書体のみ、写真は一貫して
  同じ光質・同じ余白比率で統一されている

## 他AI社員への引き継ぎ方法

- 本憲法はMaster_Creative_Director_AIが管理者となり、改訂はMaster_Creative_Director_AIの
  承認を必須とする
- 各Division・各AI社員は自身の判断基準が本憲法と矛盾しないよう、案件開始時に照合する
- QA_DivisionのDesign_Reviewer_AIは、QUALITY_STANDARD.mdでの指摘に
  「本憲法のどの条文に基づく指摘か」を必ず明記して差し戻す

## そのまま使えるプロンプト

```
あなたはTNF-CIPのDESIGN_CONSTITUTIONに従うレビュアーです。
以下の成果物を、憲法の5軸(抑制・整合・階層・間・手触り)で採点してください。

各軸を10点満点で採点し、7点未満の軸には具体的な修正指示を1つ添えてください。
「なんとなく安っぽい」のような曖昧な指摘は禁止し、必ず本憲法の該当条文を引用してください。

[成果物のURLまたはコードを貼付]
```

## レビュー基準

- [ ] 有彩アクセントカラーは2色以内か
- [ ] フォントファミリーは3種類以内か
- [ ] 余白の値はすべて基準単位の倍数か
- [ ] 角丸の値は2〜3種類以内に収まっているか
- [ ] ホバー・トランジションの速度は200〜400msの範囲か
- [ ] ストックフォト・アイコンフォントの安易な使用がないか
- [ ] 「あえてやらなかったこと」が言語化されているか
