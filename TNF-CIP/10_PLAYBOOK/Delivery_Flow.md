# Delivery_Flow

Review_Flowで「出荷可」判定を得た成果物を、クライアントへ引き渡し、
案件をクローズするまでのフロー。

## 目的

「作って終わり」ではなく、クライアントが実際に運用開始できる状態、かつ
TNF-CIP側にナレッジが資産として残る状態の両方を満たして案件を終えること。

## フェーズ

### Phase 1: 納品パッケージ作成
- **担当**: Claude_Code_Engineer_AI
- **入力**: Review_Flowで合格した実装コード一式
- **やること**: 案件フォルダ（`08_PROJECT_TEMPLATES/{種別}/{クライアント名}/`）配下に、
  下記「納品パッケージ構成」の形式で成果物を整理する
- **出力**: 納品パッケージ
- **完了条件**: 下記構成のすべての項目が揃っている

### Phase 2: クライアント引き渡し
- **担当**: CEO_AI
- **入力**: 納品パッケージ
- **やること**: クライアントに成果物を共有し、使い方（更新方法、運用上の注意）を
  説明する。フィードバック受付期間を設定する
- **出力**: クライアント受領確認
- **完了条件**: クライアントからの受領確認、またはフィードバック受付期間の設定完了

### Phase 3: フィードバック対応（発生時のみ）
- **担当**: 該当する担当AI社員（Design_Production_Flowと同じ体制）
- **入力**: クライアントフィードバック
- **やること**: 軽微な修正はReview_Flowを簡略版（Phase 1のみ）で通し、
  大幅な方向転換要望はProject_Start_Flowに差し戻す
- **出力**: 最終版成果物
- **完了条件**: クライアント承認

### Phase 4: 案件クローズとナレッジ還元
- **担当**: Style_DNA_Manager_AI + Master_Creative_Director_AI
- **入力**: 最終版成果物一式、Review_Flowの指摘履歴
- **やること**: この案件で確立した世界観・UIパターン・モーションパターンのうち、
  汎用化する価値があるものを03_STYLE_DNA/04_VISUAL_DNA/05_UI_UX_SYSTEM/
  06_MOTION_SYSTEMへの追加候補としてStyle_DNA_Manager_AIが審査する
- **出力**: ライブラリ更新提案（承認された場合は各ライブラリファイルを更新）
- **完了条件**: 案件クローズ報告がMaster_Creative_Director_AIに提出されている

## 納品パッケージ構成

```
08_PROJECT_TEMPLATES/{種別}/{クライアント名}/
├── 00_Client_Brief.md          （Client_Intake_Flowの成果物）
├── 01_Kickoff_Summary.md       （Project_Start_Flowの成果物）
├── 02_Design_Docs/             （サイトマップ・世界観ブリーフ・レイアウト仕様・
│                                  モーション仕様・コピー）
├── 03_Review_Records.md        （Review_Flowの指摘〜修正履歴）
├── 04_Final_Deliverable/       （最終実装コード・画像等）
└── 05_Handoff_Notes.md         （クライアント向け運用マニュアル）
```

## 品質基準

- 納品パッケージの5項目がすべて揃っている（欠落があれば納品不可）
- Handoff_Notesが、クライアント側の非エンジニアでも理解できる言葉で書かれている
  （社内用語・AI社員名などの内部プロセス用語を含まない）
- 案件クローズ時に、ライブラリ更新の要否がStyle_DNA_Manager_AIによって
  明示的に判定されている（「特になし」も可、判定を省略することは不可）

## NG例

```
実装コードだけをクライアントに送り、運用マニュアルもナレッジ還元も行わずに
案件を終了する。
```
クライアントが更新方法に迷う、かつTNF-CIP側に何の知見も蓄積されない、
二重の機会損失が発生する。

## 良い例

```
Handoff_Notesに「画像の差し替え方法」「コピー変更時の注意点(NG表現リスト)」を
クライアントの言葉で明記。案件クローズ時にStyle_DNA_Manager_AIが
「このカフェ業態の光の演出パターンは04_VISUAL_DNA/Cafeへ汎用化する価値あり」と判定し、
ライブラリを更新。
```
クライアントの自走を助けると同時に、次回以降の同業種案件の初速を上げている。

- GitHub_Save_Flowの最終コミット（納品タグ付け）はDelivery_Flow Phase 1と
