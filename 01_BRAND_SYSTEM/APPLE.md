# APPLE — ブランドシステム

## ブランド概要
機能ではなく「体験」を売る。製品そのものを主役にし、言葉数を極限まで削ぎ落として余白と大きなビジュアルで語らせる。プレミアム感と親しみやすさを同時に成立させ、「シンプルであることの高級感」を体現するブランド言語。

## 配色
- ベース: ホワイト `#FFFFFF` / ライトグレー `#F5F5F7`
- テキスト: ほぼブラック `#1D1D1F`
- アクセント: システムブルー `#0071E3`（CTAやリンクのみに限定使用）
- ダークモード: `#000000` 背景 + `#F5F5F7` テキスト
- 原則: 基本はモノトーン、色は製品自体（写真・映像）に語らせ、UIカラーは最小限に抑える

## フォント
- 欧文: San Francisco（SF Pro Display / SF Pro Text）
- 和文: ヒラギノ角ゴシック相当
- 見出しは大きく・太く・トラッキングをやや狭める（-0.02em程度）
- 本文は読みやすさ優先で行間1.5〜1.6

## 余白
- セクション間は画面高さの50〜100%を使うほど大胆に取る
- 要素同士の余白は8pxグリッドを基準に倍数で統一
- 「詰めない」ことこそが高級感の演出手段

## 写真
- 製品を中央に配置し、背景は無地または極端に抽象化したグラデーション
- 光の反射・質感（金属、ガラス）を美しく見せるスタジオ撮影
- 人物写真は自然光・感情が伝わる瞬間を切り取る、過度な演出をしない

## レイアウト
- 1カラム・中央寄せの縦スクロール構成
- セクションごとに主張を1つに絞る（One Message Per Section）
- グリッドは12カラムベース、大胆な非対称配置も使用

## アイコン
- 極細のラインアイコンまたはSF Symbolsベース
- 装飾ではなく機能を示すためだけに使用、数は最小限

## ボタン
- 角丸のピル型（fully rounded）
- プライマリはブルー背景+白文字、セカンダリはアウトラインまたはテキストリンク
- ホバー時はごく僅かな明度変化のみ、派手な演出はしない

## アニメーション
- スクロールに連動したパララックス、フェードイン
- イージングは`ease-out`中心で滑らかに減速
- 動きは「説明のため」に使う。装飾目的の動きは避ける

## CTA
- 「詳しく見る」「購入する」など短く明確な動詞
- 1画面に対してCTAは基本1つ、迷わせない

## コピーライティング
- 短文・体言止めを多用し、余韻を残す
- 数字やスペックは最小限、感情や体験価値を先に語る
- 例：「これまでで最も。」「驚くほど、シンプル。」

## 世界観
静けさ、余裕、完成度への信頼。声高に主張せず、製品の完成度そのものが説得力になるという哲学。ユーザーに「考えさせない」体験設計。

## Fable用プロンプト
```
Apple.com風のプレミアムプロダクトLPを作成。
- 背景は白またはごく薄いグレー、圧倒的な余白を確保
- ヒーローセクションは製品を中央に大きく配置し、コピーは1〜2行の短文のみ
- フォントはSF Pro相当のサンセリフ、太めの見出し+細めの本文
- カラーはモノトーン基調、アクセントはシステムブルーのみCTAに使用
- ボタンはピル型、控えめなホバーアニメーション
- セクションごとにスクロールでフェードイン/パララックスを付与
- 「静かで高級、説明しすぎない」トーンを一貫させる
```
