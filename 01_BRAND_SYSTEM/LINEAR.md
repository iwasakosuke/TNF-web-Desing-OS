# LINEAR — ブランドシステム

## ブランド概要
「速さ」と「精密さ」をUIそのもので証明するブランド言語。ダークモード基調、ミニマルながら情報密度が高く、プロダクト自体の完成度でブランドを語る。開発者・プロダクトチームからの信頼が厚い、モダンSaaSの象徴。

## 配色
- ベース: ダークネイビー〜ブラック `#08090A` / `#101113`
- テキスト: `#F7F8F8`（見出し）/ `#8A8F98`（本文・補助）
- アクセント: バイオレット〜インディゴ系グラデーション `#5E6AD2` を基調にワンポイント使用
- ボーダー: 極薄の`#1F2023`で要素を静かに区切る

## フォント
- 欧文: Inter（タイトなトラッキング、可変ウェイト活用）
- 和文: Noto Sans JP
- 見出しは中〜太ウェイトでサイズを抑えめに（華美な巨大見出しは避ける）
- 本文は14〜16pxとコンパクト、情報密度を優先

## 余白
- 過度に広げず、機能美を優先したタイトな余白設計（40〜80px程度のセクション間）
- コンポーネント内は4px単位のグリッドで精密に整列

## 写真
- 実写はほぼ使わず、プロダクトのUIスクリーンショット・モーショングラフィックが主役
- ダークUI上に浮かぶカード・ウィンドウのレイヤー表現

## レイアウト
- 中央寄せの縦スクロール、ヒーロー直下にプロダクトUIのビジュアルを大きく配置
- グリッドは整然としたカラム構成、要素間の整列を厳密に統一
- セクション境界はグラデーションの光やノイズテクスチャで演出

## アイコン
- 極細ラインアイコン、ピクセルパーフェクトな精密さ
- 単色（白またはグレー）で統一し、装飾よりも機能性重視

## ボタン
- 角丸小さめ（6〜8px）のコンパクトなボタン
- プライマリは白背景+黒文字、またはバイオレットのグラデーション
- キーボードショートカット表示（⌘K等）を添えて「速さ」を暗示

## アニメーション
- 高速でキレのあるトランジション（150〜250ms、easeOutQuart系）
- ホバー・クリックの反応が即座で「もっさりしない」ことを最優先
- グラデーション光がゆっくり流れる背景演出

## CTA
- 「Start building」「Get started」など簡潔で機能的な訴求
- サインアップの摩擦を減らすため、フォーム項目を最小限に見せる

## コピーライティング
- 短く、動詞先行。誇張を避け、プロダクトの機能性で語る
- 「Linear is a purpose-built tool」のような断定的で自信あるトーン
- 開発者・PMに響く専門用語を過不足なく使用

## 世界観
静かな自信と圧倒的な完成度。うるさい装飾を排し、「動かしてみれば分かる」というプロダクトファーストの哲学。ダークで洗練された、深夜の開発現場のような集中感。

## Fable用プロンプト
```
Linear.app風のダークモードSaaSランディングページを作成。
- 背景はほぼ黒に近いダークネイビー、微細なノイズテクスチャとバイオレット系グラデーションの光を配置
- ヒーローはコピー+CTAの直下に、ダークUI上に浮かぶプロダクトスクリーンショットを配置
- フォントはInter、コンパクトなサイズで情報密度を高く保つ
- ボタンは角丸小さめ、白背景+黒文字を基調、ホバーは高速でキレのあるトランジション
- アイコンは極細ラインアイコンで統一
- 全体的に「速い・精密・静かな自信」を感じるトーンでまとめる
```
