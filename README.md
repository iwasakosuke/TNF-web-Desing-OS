# TNF-web-Desing-OS

世界レベルのLP・コーポレートサイトをAIだけで高速制作できる仕組みを作る。

## 目的

TNF Web Design OSは、ブランド設計からLP・コーポレートサイト・UIコンポーネントの制作、
コピーライティング、AI（Fable / Claude）へのプロンプト設計までを一貫して管理するための
ナレッジ・アセット基盤です。制作物やノウハウをフォルダ単位で体系化することで、
誰が担当しても同じ品質・同じスピードで高品質なWebサイトを量産できる状態を目指します。

## フォルダ構成

| フォルダ | 内容 |
| --- | --- |
| `01_BRAND_SYSTEM` | ブランドガイドライン、カラー・タイポグラフィなどのブランド基盤 |
| `02_LP_TEMPLATES` | ランディングページのテンプレート・雛形 |
| `03_CORPORATE` | コーポレートサイト関連の制作物 |
| `04_SERVICE_SITE` | サービスサイト関連の制作物 |
| `05_UI_LIBRARY` | UIパーツ・デザインシステムのライブラリ |
| `06_COPY_LIBRARY` | コピーライティング・文言のライブラリ |
| `07_FABLE_PROMPTS` | Fable向けプロンプト集 |
| `08_CLAUDE_PROMPTS` | Claude向けプロンプト集 |
| `09_COMPONENTS` | 再利用可能なコンポーネント集 |
