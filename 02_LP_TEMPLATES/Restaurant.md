# Restaurant — LPテンプレート

## Hero
- キャッチコピー: 「特別な一夜を、確かな一皿で。」
- サブコピー: 旬の食材を活かした〇〇（ジャンル）料理と、選び抜いたワインのペアリング
- ビジュアル: シェフが仕上げる料理のクローズアップ、落ち着いた照明の店内
- CTA: 「コースを見る」「予約する」

## Problem
- 「記念日にふさわしいお店が見つからない」
- 「本当に美味しい料理と、丁寧な接客を両立した店を探している」
- 「予約サイトだけでは雰囲気や料理の詳細が伝わらない」

## Solution
- シェフ自ら市場で選ぶ旬の食材による季節限定コース
- ソムリエ厳選のワインペアリングで料理の魅力を最大化
- 記念日・接待に対応する個室と、細やかなホスピタリティ

## Feature
1. 季節替わりのおまかせコース
2. ソムリエによるワインペアリング
3. 個室完備（記念日・接待対応）
4. アレルギー・食事制限への柔軟な対応
5. オンライン予約・事前決済対応

## Voice
- 「誕生日のサプライズに利用しました。料理の説明も丁寧で感動しました。」（30代・カップル）
- 「接待で使いましたが、個室の落ち着いた雰囲気がとても良かったです。」（40代・経営者）
- 「ワインペアリングが絶妙で、料理の印象がより深まりました。」（50代・夫婦）

## Flow
1. Webサイトでコース・空席状況を確認
2. オンラインで日時・人数・コースを予約
3. 来店、シェフによるおまかせコースを楽しむ
4. 会計・次回予約の案内
5. メールマガジンで季節限定メニューの案内を受け取る
