# 画像の差し替えについて

このLPは画像がまだ無い状態でも、ダークな仮グラデーションで動くように作られています。
以下のファイルをこのディレクトリに置くと、コードを変更せずに自動で表示されます。

- `public/hero.png` … トップのメインビジュアル（ゆっくり拡大するアニメーション付き）
- `public/works/01.jpg` 〜 `06.jpg` … 横に流れる作例帯の画像
- `public/cases/01.jpg` 〜 `04.jpg` … カードが重なるセクションの背景画像（現状は透明度0で無効化中。使う場合は `src/components/StackingCards.tsx` の `opacity-0` を外してください）
