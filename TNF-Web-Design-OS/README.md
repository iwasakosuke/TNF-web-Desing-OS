# TNF Web Design OS v1

## 目的

TNF Web Design OSは、AIを活用してLP（ランディングページ）・会社ホームページ・サービスサイトを
「高速」かつ「高品質」に制作するための社内制作OSです。

これまで属人化していたデザイン判断・コピーライティング・実装ルールを、フォルダごとに構造化された
ドキュメント（ブランドシステム、LPテンプレート、UIライブラリ、コピーライブラリ、AI用プロンプト集）
として体系化し、誰が着手しても同じ品質基準・同じスピードで制作できる状態を作ることを目的とします。

Fable（ビジュアル生成AI）とClaude（コード生成・文章生成AI）を組み合わせ、企画〜デザイン〜実装〜
レビューまでの制作フローを一気通貫でAI駆動にすることで、従来数週間かかっていたサイト制作を
数日単位に短縮します。

## 使い方

1. **00_RULES** で制作全体の基本ルール・デザイン原則を確認する
2. 案件の業種・目的に応じて **01_BRAND_SYSTEM** からブランドトーンを選定する
3. LP案件は **02_LP_SYSTEM**、コーポレートサイト案件は **03_CORPORATE_SYSTEM**、
   サービスサイト案件は **04_SERVICE_SYSTEM** から該当テンプレートを選ぶ
4. **05_UI_LIBRARY** と **06_COPY_LIBRARY** を組み合わせて、UI構成とコピーの骨子を作る
5. **07_FABLE_LIBRARY** のプロンプトを使ってビジュアル・ビジュアルイメージを生成する
6. **08_CLAUDE_PROMPTS** を使って、ブリーフ生成・LP文章生成・レビューをAIに実行させる
7. **09_CLAUDE_CODE** のテンプレートを使って、HTML/Tailwind/WordPressへの実装に落とし込む
8. 各mdファイルは制作を重ねるごとに知見を追記し、OS自体をアップデートし続ける

## 4日間ロードマップ

### Day 1：ルール・ブランド基盤の整備
- 00_RULES（CLAUDE.md / DESIGN_PRINCIPLES.md）の内容を確定
- 01_BRAND_SYSTEM の各ブランドトーンに具体的な配色・フォント・世界観を追記

### Day 2：業種別テンプレートの拡充
- 02_LP_SYSTEM / 03_CORPORATE_SYSTEM / 04_SERVICE_SYSTEM の各テンプレートに
  実際のコピー・構成案を追記
- 06_COPY_LIBRARY にHero/CTA/Problem/Trustのコピーパターンを蓄積

### Day 3：UI・ビジュアル資産の整備
- 05_UI_LIBRARY に各コンポーネントの構造・スタイルガイド・実装例を追記
- 07_FABLE_LIBRARY に業種別ビジュアル生成プロンプトを整備

### Day 4：AI運用フローの確立と実案件テスト
- 08_CLAUDE_PROMPTS（ブリーフ生成・LP生成・レビュー）を実際に運用して精度検証
- 09_CLAUDE_CODE のテンプレートを使って実案件を1本、企画〜実装まで通しで制作
- 制作を通じて見つかった改善点を各mdファイルにフィードバックし、OSをアップデート

## 実行手順：「Cafe Verde」LPを作る

架空のイタリアンカフェ「Cafe Verde」を題材に、以下5ファイルだけを使ってLPを完成させる
最短フローのサンプル。初めてこのOSを使う人は、まずこの手順をなぞって全体像を掴む。

使用ファイル：
- `00_RULES/CLAUDE.md`
- `01_BRAND_SYSTEM/VERDE.md`
- `02_LP_SYSTEM/Cafe_LP.md`
- `07_FABLE_LIBRARY/Cafe_Visual.md`
- `09_CLAUDE_CODE/HTML_LP_Template.md`

**Step 1. ルールを読み込む**
`00_RULES/CLAUDE.md` を読み、Claudeが「ブランドディレクター/LPプランナー/コピーライター/実装エンジニア」
のどの役割で動くべきかを確認する。今回はLP1本の企画〜実装までを通しで行うため、全役割を横断する。

**Step 2. ブランドを解釈する**
`01_BRAND_SYSTEM/VERDE.md` を読み込み、色・フォント・余白・写真・光・コピーの口調・NG表現を把握する。
このブランドファイルの内容から逸脱しないことを、以降すべての工程で守る。

**Step 3. LP構成とコピーを確定する**
`02_LP_SYSTEM/Cafe_LP.md` のHero〜CTAまで9セクションを確認し、店名・住所・料金など実際の情報が
決まっている場合はプレースホルダー（〇〇）を差し替える。コピーはVERDEの口調を踏襲して調整する。

**Step 4. ビジュアルをFableで生成する**
`07_FABLE_LIBRARY/Cafe_Visual.md` の「外観／店内／料理／コーヒー／モーニング／ランチ／植物／手元／
余白素材」9カテゴリの英語プロンプトをFableに投げ、各セクションに必要な画像を生成する。
生成した画像は `Cafe_LP.md` の各セクション「使用画像」欄と対応づけてファイル管理する。

**Step 5. HTMLに実装する**
`09_CLAUDE_CODE/HTML_LP_Template.md` の雛形HTMLをそのまま `index.html` として保存し、
`[IMAGE: ...]` コメント箇所にStep4で生成した画像パスを差し込む。プレースホルダーの店舗情報も
Step3で確定した内容に置き換える。

**Step 6. レビューする**
`00_RULES/CLAUDE.md` のデザイン品質基準（余白・ブランド一貫性・タイポグラフィ階層・画像の質・
モーション・アクセシビリティ）に沿ってセルフレビューし、375px/768px/1440pxでの表示崩れを確認する。

**Step 7. 公開・ナレッジ還元**
完成したLPを確認後、制作過程で得た知見（コピーの言い回し、うまくいった画像プロンプト等）を
該当ファイルに追記し、次回以降のカフェ業態LP制作をさらに速くする。
