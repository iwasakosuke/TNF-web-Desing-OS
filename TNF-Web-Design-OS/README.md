# TNF Web Design OS v1

## 目的

TNF Web Design OSは、AIを活用してLP（ランディングページ）・会社ホームページ・サービスサイトを
「高速」かつ「高品質」に制作するための社内制作OSです。

これまで属人化していたデザイン判断・コピーライティング・実装ルールを、フォルダごとに構造化された
ドキュメント（ブランドシステム、LPテンプレート、UIライブラリ、コピーライブラリ、AI用プロンプト集）
として体系化し、誰が着手しても同じ品質基準・同じスピードで制作できる状態を作ることを目的とします。

Fable（ビジュアル生成AI）とClaude（コード生成・文章生成AI）を組み合わせ、企画〜デザイン〜実装〜
レビューまでの制作フローを一気通貫でAI駆動にすることで、従来数週間かかっていたサイト制作を
数日単位に短縮します。

## 使い方

1. **00_RULES** で制作全体の基本ルール・デザイン原則を確認する
2. 案件の業種・目的に応じて **01_BRAND_SYSTEM** からブランドトーンを選定する
3. LP案件は **02_LP_SYSTEM**、コーポレートサイト案件は **03_CORPORATE_SYSTEM**、
   サービスサイト案件は **04_SERVICE_SYSTEM** から該当テンプレートを選ぶ
4. **05_UI_LIBRARY** と **06_COPY_LIBRARY** を組み合わせて、UI構成とコピーの骨子を作る
5. **07_FABLE_LIBRARY** のプロンプトを使ってビジュアル・ビジュアルイメージを生成する
6. **08_CLAUDE_PROMPTS** を使って、ブリーフ生成・LP文章生成・レビューをAIに実行させる
7. **09_CLAUDE_CODE** のテンプレートを使って、HTML/Tailwind/WordPressへの実装に落とし込む
8. 各mdファイルは制作を重ねるごとに知見を追記し、OS自体をアップデートし続ける

## 4日間ロードマップ

### Day 1：ルール・ブランド基盤の整備
- 00_RULES（CLAUDE.md / DESIGN_PRINCIPLES.md）の内容を確定
- 01_BRAND_SYSTEM の各ブランドトーンに具体的な配色・フォント・世界観を追記

### Day 2：業種別テンプレートの拡充
- 02_LP_SYSTEM / 03_CORPORATE_SYSTEM / 04_SERVICE_SYSTEM の各テンプレートに
  実際のコピー・構成案を追記
- 06_COPY_LIBRARY にHero/CTA/Problem/Trustのコピーパターンを蓄積

### Day 3：UI・ビジュアル資産の整備
- 05_UI_LIBRARY に各コンポーネントの構造・スタイルガイド・実装例を追記
- 07_FABLE_LIBRARY に業種別ビジュアル生成プロンプトを整備

### Day 4：AI運用フローの確立と実案件テスト
- 08_CLAUDE_PROMPTS（ブリーフ生成・LP生成・レビュー）を実際に運用して精度検証
- 09_CLAUDE_CODE のテンプレートを使って実案件を1本、企画〜実装まで通しで制作
- 制作を通じて見つかった改善点を各mdファイルにフィードバックし、OSをアップデート
